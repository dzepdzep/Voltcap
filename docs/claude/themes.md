# Themes & animated scenes

Read only for theme/scene/shader work.

## Pieces
- `src_copy/ui/theme/ShelfColors.kt`: `ThemeMotif` enum (scene id; flags `reactive` + `reactiveHalf` for music scenes, `showcase` for non-shader game showcase), `ThemeGroup` (theme browser groups), `MusicLoop` (background music tracks), `AppTheme` (label, motif, group, palette), `ShelfTheme`.
- `tools/themes/scenes/<name>.agsl`: one scene per file, AGSL in the GLSL ES 1.0 subset (same text runs in the WebGL preview). `_prelude.agsl` is prepended to all; `//#include name` pulls in `_name.agsl` (`_reactive`, `_anime`, `_voltcap`, `_falling`).
- `tools/themes/gen.py`: `MOTIFS` list maps `ThemeMotif` name → scene file. Writes `src_copy/ui/ThemeShaders.kt` (GENERATED — never hand-edit) and `tools/themes/preview.html`. Also reads palettes and reactive motifs from `ShelfColors.kt`.
- `src_copy/ui/ThemeScene.kt`: `ThemeScene()` / `CodeScene()`, `SceneShader` (sets uniforms), `SceneClock`, `LocalSceneQuality`, `LocalSceneCovered`, idle frame rates (`HomeIdle`).
- `src_copy/ui/ThemeSceneLegacy.kt`: canvas fallback for Android < 13 / failed shader compile (needs a branch per motif).
- `src_copy/ui/ThemeThumbs.kt`: theme browser thumbnails + per-theme icon.
- Music scenes: `ui/NowPlayingScene.kt`, `ui/MusicTheme.kt`, `data/MusicThemeSettings.kt`. Game showcase / CRT room: `ui/ShowcaseScene.kt`. Kotlin-drawn themes: `ui/RetroBounce.kt`, `ui/LyricScatter.kt`.

## Adding / changing a scene
1. Edit or add `tools/themes/scenes/<name>.agsl`.
2. New scene: add the `ThemeMotif` entry + `AppTheme` entry in `ShelfColors.kt`, add `("MOTIF", "file")` to `MOTIFS` in `gen.py`, a fallback branch in `ThemeSceneLegacy.kt`, an icon in `ThemeThumbs.kt`.
3. `python tools/themes/gen.py` (add `--partial` only to rebuild the preview with scenes missing).
4. `python tools/themes/check_uniforms.py` (headless Chromium/Playwright): every uniform listed for a scene must really be active.

## Hard rules (crash/quality history)
- Android 13 aborts the app if a uniform or child shader the compiler stripped is set. Only set what `ThemeShaders.uniforms()` / `children()` list; gen.py derives them, so keep uniform use real (no `x * 0.0` tricks).
- Never `pow(negative, …)` (NaN → black). Use `sqf(x)` from `_prelude.agsl`.
- Picture uniforms: `uArt`, `uCover`, `uLabel`, `uHistory`, `uShot`. Low quality uses `uLod` to skip detail.
- Respect performance: background quality (`SceneQuality`), Lite effects, idle slow-down, still frame while covered; second screen runs one quality step lighter.
- Original designs only: no trademarked names, characters or logos.

## Custom themes & visualizers (user packs)
One text file each (`// voltpack: 1`, `// name:`, `// kind: theme|visualizer`, then `voltScene` / `voltViz`). Stored in `filesDir/custom_packs/<id>.agsl`; chosen via `Features.customScenePack` / `customVizPack`; switched off by `PackGuard` into `Features.customPackOff`.
- `ui/CustomPackRules.kt`: pure Kotlin rules (`PackRules` limits, `CustomPackRules.validate`, `buildSource`, `uniformsOf`). Size, loop shape/count/nesting, no uniforms/pictures/main/#/while/recursion, a cost budget (100 % = `MAX_COST`).
- `ui/CustomPackShaders.kt`: GENERATED by `tools/themes/gen_pack_prelude.py` from `_prelude.agsl` + `_reactive.agsl` (run it after editing either). Packs get only the uniforms in `uniformsOf`; the wrapper `main()` keeps every one alive (`keep < -1.0e20`) so Android 13 never sees a stripped uniform.
- `ui/CustomPacks.kt`: store, import (validate → test-compile with `RuntimeShader` → save), `active(motif)`, `SceneSource` (router the scene code reads instead of `ThemeShaders` for `motif.custom`), `rememberEffectiveMotif` (falls back to `VOLT_INTRO` / `MUSIC`), `PackGuard` (scale cap 0.6 / 0.75, ~30 fps, heavy mode, auto-off after a second `FrameWatch` step).
- `ui/CustomPacksUi.kt`: Settings › Theme › "Your own themes & visualizers" card, pack page (budget meter), and the how-to dialog (round Volt "?" via `VoltTopic.CUSTOM_PACKS`).
- Motifs `CUSTOM_SCENE` / `CUSTOM_VIZ` (`ThemeMotif.custom`) and themes `CUSTOM_THEME` / `CUSTOM_VISUALIZER` (group "Your own") exist so the theme list works; gen.py emits `-> ""/emptySet()` for them to keep the `when`s exhaustive and skips them in the preview. Their palettes must stay unique (NowPlayingScene treats a reactive theme's exact palette as "use the cover's colours").
- Change a limit in `PackRules` only; the tutorial text reads the constants. Re-run `PackTest` (validator) and the WebGL check after editing the prelude.
