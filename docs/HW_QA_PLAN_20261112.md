# Hardware QA plan — prepared 12 Nov 2026, NOT RUN (no handheld qualified)

**Applies only when a handheld passes the existing gates:**
- connected by USB with a known serial (KONKR `BW0306N230000845`, Flip 2 `2037b27d`, Thor `3140972f`); never the wireless Google TV Streamer or the Odin2 Portal;
- awake and unlocked; it is never woken or unlocked for this;
- the real Voltcap (`com.shelf.launcher`) is NOT in front.

**How every run behaves:**
- Every step runs in the separate QA app (`com.shelf.launcher.qa`, debug key).
- Every key press is gated: if the QA app loses the front, the run stops with no further input.
- Nothing is installed over production, no data is cleared, no system setting is changed, and an unavailable device is not polled again and again.
- Each run records `screenrecord` video, `gfxinfo` frame stats and the `VoltcapQA` trace into `/sdcard/pc/<area>/`. They are pulled to `Claude outputs\hwqa\<date>\`.

**Before and after every session:**
- `sh shelf3d_qa.sh base` (or `ci_qa.sh base`): the real Voltcap's version, install time and path must be identical.
- Install only with the tool's guarded `install_build` (QA identity + signer + USB checked), from the `pnat` worktree (or `s3d` once active).
