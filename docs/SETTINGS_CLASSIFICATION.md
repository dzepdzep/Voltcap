## Overlapping decisions
These are each settled by one function and tested:
- **What A opens (5 keys):** `winPresentation` (`WinPresentationTest`, 11,872 combinations).
- **"A plays" (2 keys):** popup-first defaults.
- **Box sides (3 keys).**

**Different results across layouts.** A layout with its own popup style ignores the global "banner" / "row motion" default. That is the documented precedence, but it isn't shown in Settings › Game window, so it's a candidate for the later settings redesign (not done now).
