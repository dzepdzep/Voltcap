# Voltcap — real editions and materials (update 210)
Made from the same list as `ui/MediaEditions.kt` and `ui/ShellMaterials.kt`. **All colours are approximate sRGB rendering presets** (from the V3 spec), not manufacturer values or measured samples; they still need tuning against real photographs.
**Status:** *Verified retail* — a real release, with the source below. *Verified alternate* — a documented second official release (a grey re-run). *Pending research* — plausible, not yet confirmed: offered in Cartridge shell…, never picked by itself.
**Picked by itself (auto):** only a Verified retail edition with no other documented edition of the same game, when the ROM's file name states the region and every region it names had that edition. Everything else is only offered in the game's menu › Cartridge shell…
**Matching:** by the ROM file name (No-Intro style), normalised (brackets dropped, "The" dropped, punctuation removed). Never by file size or similar titles.

## Known uncertainties

- **Colours:** every value is a design estimate; none has been compared side by side with a photograph yet.
- **Pokémon FireRed:** Game Verifying's casing page says orange, its GBA depository translucent red — drawn as a provisional red-orange, less see-through than Ruby.
- **Pokémon Silver (western):** not in the part of Game Verifying's casing list that loaded; widely documented, colour approximate.
- **Japanese Pokémon Gold / Silver two-tone, Australian DK64 / Ocarina of Time, PAL Turok 2:** from the V3 spec, not re-checked — Pending research.
- **WCW Backstage Assault grey:** listed by micro-64 but disputed as a US release (region markings) — Pending.
- **micro-64:** its table marks 14 games "Gray variant? Yes" while its text says 13 (WCW is the disputed one).
- **Pokémon Pinball:** the rumble shell is assigned; its colours by region (western black, Japanese yellow / black) not confirmed — the shell's own colour is drawn.
- **Mobile Series (GBC, Japan):** "clear blue" confirmed, which titles belong to it not — Pending.
- **Yoshi Topsy-Turvy:** green and white — which half is which not confirmed; PAL copies have a different front casing (not drawn).
- **Special shells' shapes** (Boktai, Drill Dozer, WarioWare: Twisted!, Yoshi Topsy-Turvy, Kirby Tilt 'n' Tumble, Pokémon Pinball) are still estimated outlines (CARTRIDGES.md), not measured.
- **Not covered yet:** DSi-exclusive white cards (no title list), Famicom Mini (which title has which colour), Game Boy Camera / Pocket Sonar / Pokémon TCG shells' colours, Famicom per-publisher shells, colour editions on Atari / SNK / NEC / Bandai, custom disc finishes (rainbow, holographic) and the specialty hardware geometry beyond the existing outlines.
