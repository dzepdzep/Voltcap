- **Recorder:** two failure kinds seen today — screenrecord running on without frames, and recorder + watcher gone together. New
  `rec.sh` (own session, segments, early-stop log, end screenshot) + `recheck.py` (grades from real frames / decode; a short file is
  excused only if its last frame is the screen at the stop). Applied to `popvid.sh`, `s525.sh`, `ci525.sh`. Root cause unconfirmed.

  48c546e — "5 values … no hit; no secret files", MATCH. Still only pnat / s3d / ci pushable.
