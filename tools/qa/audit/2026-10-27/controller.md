# VoltCap controller-accessibility audit (static)

Source: `src_copy/` (read-only). Paths are relative to `src_copy/ui/` unless noted. ThemeShaders.kt not read.
Ground rules I checked against: `docs/claude/input-screens.md`. Required buttons there are D-pad, A/B/X/Y, L1/R1, L2/R2, Start and Select. L3/R3 and the right stick are **not** on that list.

## Touch-only by design or decorative (no action)
- Home layouts (Style*.kt, Twin*, Pocket*, CubeHub, Tile/Grid/Hero homes): `tapOnly`/`detectTapGestures` mirror the StyleNav, HomeReach and PocketNav key maps. TwinSharedCategoryStrip is opt-in and duplicates L1/R1.
- Status-bar search, notifications, profile, trophy and accessories: Y/R1, Profile hub, Achievements and Settings > Device info cover them.
- GameWindowBanner.kt:833-838, 986-992 (`canFocus = false` ✕ and L1/R1 hints): B, L1 and R1 do the same things.
- GuideScreen `ScrollNub` (D-pad scrolls), ArtworkGallery tap thirds (◀ ▶ A B), FullScanCutEditor drag (it has ◀ ▶ chips), QuickSettings tile drag (A picks, then the D-pad moves), ShortcutsPanel drag (hold A + D-pad, X removes), PlatformBrowser slide editor drag (keys at :251-261), HomeEdit drag and pinch (keys at HomeEdit.kt:479-526), Edit Home "Fold" tab (cosmetic), WidgetBoard drag (padTarget edit keys).
- CompanionHub / CompanionActivity (in game, the controller belongs to the game), ScreenMirror trackpad, SecondScreenMagnifier pinch: touch by necessity.
- Scrim `detectTapGestures {}` / `clickable(enabled=false){}` blockers: decorative.

## Screens that look fully OK
Settings (requests initial focus, B goes back to the sub-page list, sliders and switches keyed). R1 Quick settings (keyed reorder, L1/R1 pages). Mixer (`VolumeBar`, first-focus, B). SaveExplorer and SaveInspectDialog entry (Inspect chip). App drawer (Start = menu). Shortcuts panel. Year recap (full key map). Artwork gallery. Game window, classic and TV (all icon buttons are focusable `WinIconButton`; page flip has buttons). Platform browser and its slide editor. Edit Home (full key map plus inspector). The home search bar (B / A / ▼ leave the field). `ShelfTextField` everywhere (no raw text fields elsewhere; B folds it). Manual reader, Guide, CrossTrophies, Tips (own key handling). Second-screen Home tabs and pages, dock launch, drawer, Games page folders (open), Widget Board, Mixer (padTarget coverage).

## On-device checks for the PLAUSIBLE items
1. **C1**: Retroid/Odin landscape → game → Start (options) → "Cartridge shell…" → hold ▼. Expect every shell tile to be reachable, scrolled into view and ringed.
2. **C8**: Pocket Classic (no sticks) → game window → Inspect icon → try to open the case and take out the cartridge without touch. Then Save Explorer → a save → Inspect → try to rotate.
3. **C16**: R1 → a tile with a hold action (e.g. Wi-Fi/Lights) → hold A for 1 s. Expect its settings to open. Repeat on a device whose B/A send BUTTON_A/BUTTON_B (not DPAD_CENTER/BACK).
4. **C17**: Home → Select (Sort, Library, Game options…) → press A immediately without a D-pad press. Note whether anything is focused or ringed. Then press ▼ once and check that focus lands on the first row, not the last or the footer.
5. **C12**: R1 → Shortcuts → ▶ along the tiles. Check that no press lands on the ✕ badge with no ring.
6. **C13**: one-screen device with the virtual second screen on → home grid → hold ▶ at the last column. Check that focus never jumps to the "2" tab.
7. **C9**: Settings → any page with two-column cards and a slider in the right column → ◀ on the slider at 0 %. Confirm focus stays (the expected result for the current code).
