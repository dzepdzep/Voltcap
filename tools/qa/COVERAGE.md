# VoltCap QA coverage matrix

Generated by `python3 tools/qa/tools/coverage.py render` from the repository (`HomeLayout`, `tools/qa/coverage.json`, `tools/qa/audit/*/layouts_auto.json`). **Do not edit by hand**; CI fails when it is out of date.

Statuses: **PASS** ran with valid evidence and found nothing; **FAIL** ran and found a defect; **SKIP** deliberately not run; **NOT TESTED** nothing ran (no device, unsafe, not built). SKIP and NOT TESTED are never counted as PASS. `INFRA` = the evidence could not be used (says nothing about the app). `REVIEW` = the tool flagged something a human must look at; it is not a verdict.
